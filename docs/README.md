# Изборна аналитика — GitHub Pages

GitHub Pages приказ користи `docs/index.html`. Почетна страна нуди **„Отвори постојеће податке”** и **„Учитај свој CSV”**. Постојећи скуп се не отвара аутоматски.

Сопствени CSV се чита, проверава и анализира у прегледачу. Датотека и њен садржај не шаљу се на GitHub или други сервер. За први обрачун прегледач преузима Pyodide 0.27.8 и библиотеке NumPy, pandas, SciPy и Shapely са званичне Pyodide дистрибуције преко jsDelivr-а. Потребна је интернет веза и савремен прегледач; обрада већих CSV-ова најбоље ради на рачунару.

Обрачун користи исти Python код као локална апликација. Доступни су повезивање колона, провере података, анализе цифара, мапе, оба модела симулације и извоз сопственог HTML/ZIP извештаја. CSV табеле се могу преузети из одговарајућих приказа.

Нови CSV не наслеђује статистичке резултате другог скупа. За повезивање места у иностранству, исти CSV може користити потврђени профил; за измењен CSV поклапања су само предлози које треба потврдити. Неповезана места остају у бројчаним анализама.

HTML који корисник извезе садржи своје податке и обрачуне који су већ покренути. За необрачунат избор приказује се да резултат није укључен. Нови CSV и нове симулације могу се поново покренути у верзији странице која има избор учитавања података. Готови обрачуни и графикони могу да се читају без додатних библиотека.

## Освежавање објављене верзије

Из корена пуног локалног пројекта покрените:

```powershell
.venv\Scripts\python.exe docs\azuriraj.py
```

Команда освежава изглед постојећег извоза из `dist/izbori-2026`, па синхронизује његове датотеке у `docs`. Сачувани статистички резултати и CSV табеле се при томе не рачунају поново. У репозиторијуму који садржи само готов извоз, команда проверава постојећи `docs`. Други извоз за копирање може се задати опцијом `--source`.

Провера без измена:

```powershell
python docs\azuriraj.py --check
```

Затим прегледајте и комитујте `docs`:

```powershell
git add docs dist/izbori-2026
git commit -m "Освежи Pages апликацију и додај сопствени CSV"
git push
```

У GitHub подешавањима **Settings → Pages** задржите своју грану и фасциклу **`/docs`**. Датотека `.nojekyll` омогућава објављивање готовог HTML-а. `azuriraj.py` сам не комитује, не гура измене и не мења подешавања GitHub-а. Постојеће додатне датотеке у `docs`, укључујући `CNAME`, остају сачуване.

## Шта је у пакету

`index.html` садржи приказ, локално упаковане графичке библиотеке, логотипе, студије, границе, објављене податке и Python код за обраду у прегледачу. `stations.csv` и `results.csv` су пратеће табеле објављеног скупа. `manifest.json` бележи његово порекло и подешавања. `github-pages.zip` садржи ове четири датотеке. Избор сопственог CSV-а не преписује ове датотеке у GitHub репозиторијуму.
